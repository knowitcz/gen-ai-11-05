# Happy Bank — Web Frontend

React + TypeScript single-page application built with Vite, styled with Tailwind CSS and shadcn/ui, tested with Vitest and React Testing Library.

See the *Frontend* section of the [project README](../../README.md) for how to run, test and build it. The plan behind it is in [docs/HB-13/frontend](../../docs/HB-13/frontend/plan.md).

## Layout

- `src/api` — typed calls of the backend API
- `src/types` — the shapes of the API data
- `src/pages` — one component per route
- `src/components` — shared components; `src/components/ui` is generated by shadcn/ui
- `src/hooks`, `src/lib` — helpers
- `src/test` — test setup and helpers
